Работаем над этапом $ARGUMENTS из @docs/PLAN.md (раздел «План работ по шагам»).

1. Прочитай этап и посмотри текущий код репозитория. Ничего не меняй.
2. Составь план: какие файлы создать или изменить, в каком порядке, какие тесты написать, что нужно от меня (ключи, токены, решения). Покажи план и дождись моего «ок».
3. Реализуй по плану модуль за модулем. После каждого модуля — `uv run pytest -q tests/<файл>` и `uv run ruff check`. Показывай вывод.
4. В конце: весь набор тестов, краткий список изменённых файлов, что я должен проверить руками (например, `uv run python -m digest.cli <url>`).
5. Предложи сообщение коммита на английском. Коммить только после моего подтверждения.

Не делай функционал следующих этапов. Если в плане что-то спорно или устарело — спроси, а не угадывай.

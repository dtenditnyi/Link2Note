# Перенос assistant_bot → Link2Note

**Перенос завершён 09.11.2026** (этап 0, см. docs/specs/stage-0-migration.md). Папка `legacy/` удалена; оригинал assistant_bot хранится отдельно.

## Что было в старом боте
| Файл | Что делает |
|---|---|
| `main.py` | Bot + Dispatcher, 4 роутера, `init_db()`, планировщик, polling |
| `database.py` | SQLite `reminders.db`: таблица `reminders` (id, chat_id, task, remind_at, status), CRUD |
| `scheduler.py` | APScheduler: задача на каждое напоминание, восстановление задач при старте |
| `utils.py` | `parse_reminder_time`: HH:MM, HH:MM:SS, YYYY-MM-DD HH:MM[:SS] |
| `handlers/basic.py` | `/start` с кнопками «Создать напоминание» / «Мои напоминания», `/cancel` |
| `handlers/reminders.py` | Создание напоминания через FSM (текст → время), список |
| `handlers/callbacks.py` | Карточка напоминания, изменить время, удалить, «Назад» |
| `handlers/voice.py` | Голос → faster-whisper (small, CPU) → Ollama `qwen2.5` → JSON {task, remind_at} → напоминание. Плюс «память» текста на 15 мин как контекст к голосовому |
| `handlers/ai_parser.py` | пустой |
| `Dockerfile`, `docker-compose.yml` | python:3.14-slim + ffmpeg, сервис `ollama` |

## Найденные проблемы (исправить при переносе)
1. **Нет фильтра по владельцу** ни в одном хендлере: любой, кто найдёт бота, может им пользоваться (и грузить Whisper/LLM).
2. **Изменение и удаление по id без проверки chat_id** (`callbacks.py`): можно трогать чужие напоминания.
3. **`parse_reminder_time`**: для форматов с датой возвращается datetime **без часового пояса**, для HH:MM — с поясом. Прошедшие даты не отклоняются.
4. **Пропущенные напоминания теряются**: `restore_jobs` пропускает всё, что должно было сработать, пока бот был выключен.
5. **Список напоминаний** показывает и уже отправленные (status не учитывается и не отображается).
6. **`catch_context` ловит любой текст**, отвечает «Запомнил контекст» на каждое сообщение и будет перехватывать ссылки для Link2Note.
7. **Whisper грузится при импорте модуля**: медленный старт, тесты не импортируют хендлер без модели. Голосовой файл пишется в текущую папку.
8. `reminders_keyboard` продублирован в двух файлах. Часовой пояс захардкожен в трёх местах. Хост и модель Ollama захардкожены.
9. В промпте LLM примеры с прошедшими датами. `requirements.txt` был в UTF-16 (заменяется `pyproject.toml`). Dockerfile на Python 3.14, проект — на 3.12.

## Целевая структура
- `config.py` — все настройки (в т.ч. TZ, модель LLM, путь к БД).
- `database.py` — одна БД: таблицы `reminders` и `digests`.
- `scheduler.py` — напоминания + (этап 3) воскресный дайджест.
- `handlers/` — `basic`, `reminders` (+ callbacks), `voice`, `links`; общий фильтр владельца на уровне роутера/middleware.
- `services/` или `digest/` — логика без Telegram (парсинг времени, LLM, транскрибация), чтобы её можно было тестировать.

## Маршрутизация сообщений (новое)
- Сообщение **со ссылкой** → Link2Note (очередь конспектов).
- Голосовое → Whisper → разбор намерения (напоминание / идея-заметка, этап 3).
- Обычный текст без ссылки → контекст для следующего голосового (как раньше), но без ответа на каждое сообщение.

## Решения, которые принимаю я (спросить перед переносом)
- LLM для голосовых напоминаний: оставить **Ollama qwen2.5** (локально, бесплатно, тяжёлый контейнер) или перейти на **Gemini** (ключ уже есть, structured output), или сделать переключатель `LLM_PROVIDER`.
- Модель Whisper: оставить `small` на CPU?

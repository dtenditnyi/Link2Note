# Как добавлять любую функцию в Link2Note

Обязательный порядок для **каждой** новой функции, переделки или переноса кода. Пропускать шаги можно только для мелочей, где diff описывается одной фразой (опечатка, переименование, лог).

## 1. Понять задачу
- Перескажи задачу своими словами в 1–2 предложениях.
- Если что-то неясно или есть несколько разумных вариантов — спроси (AskUserQuestion), не угадывай.

## 2. Исследовать
- **Код проекта:** что уже есть, что переиспользовать, что сломается. Ищи через LSP/Grep, читай только нужные файлы.
- **Документация библиотек:** сверь API через Context7 (aiogram 3, google-genai, yt-dlp, APScheduler и т.д.), не по памяти.
- **Интернет:** как это обычно делают, готовые решения, известные проблемы (WebSearch). 3–5 находок со ссылками.
- **Чего не хватает:** edge cases, ошибки, безопасность, что улучшить сверх запроса — предложи, но не делай без согласия.

## 3. План и критерии готовности
- Покажи план: какие файлы создать/изменить, порядок, что нужно от меня.
- Список **критериев приёмки** — проверяемые утверждения («ссылка youtu.be/ID и /shorts/ID дают один normalize», «чужой user_id игнорируется»).
- Для крупных функций сохрани спецификацию в `docs/specs/<название>.md`.
- **Жди моего «ок».**

## 4. Сначала тесты
- Напиши тесты по критериям из шага 3 (pytest, сеть и LLM мокаются).
- Запусти: новые тесты должны **падать** по правильной причине. Покажи вывод.

## 5. Код
- Минимальная реализация, чтобы тесты прошли. Модуль за модулем.
- После каждого модуля: `uv run pytest -q tests/<файл>`.
- **Не меняй тест, чтобы он прошёл.** Если тест неверный — объясни почему и только потом правь.

## 6. Проверка
- Весь набор: `uv run pytest -q` и `uv run ruff check .`. Покажи вывод.
- Ревью субагентом: diff против критериев из шага 3. Исправляй только реальные проблемы (корректность, требования), стиль — по желанию.
- Скажи, что мне проверить руками и какой командой.

## 7. Завершение
- Обнови `docs/PLAN.md` (отметь сделанное) и `CLAUDE.md`, если поменялись команды или правила.
- Предложи сообщение коммита на английском. Коммить только после моего подтверждения.
